JOKERCALLBREAK - Call Break for 4 or 8 players

Check that everything works:   npm test      (expect: fail 0)
Start the game:                npm start
Open in your browser:          http://localhost:3000

Modes: Standard (4 players), Partnership (4 players), Partnership (8 players, 2 decks).
Computer players can fill empty seats, so you can try any mode on your own.

Files: src/ = rules and server, public/ = the website (index.html, style.css, app.js).
To put it online for free, follow DEPLOY.txt.
